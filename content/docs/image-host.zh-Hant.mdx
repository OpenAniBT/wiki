AniBT 為入駐字幕組提供專屬的圖片託管服務，方便在釋出動漫資源時上傳高畫質海報、劇集預覽截圖以及版本說明圖。

<Callout type="info">
  圖床服務僅對字幕組成員開放，入口位於控制台 `/groups/<slug>/image-host`。支援主流常見圖片格式，單張上傳上限為 **10 MiB**。
</Callout>

## 圖片上傳與排版防抖

釋出頁面如果直接引用無尺寸資訊的外部圖床圖片，當使用者網路較慢時，圖片載入完成後會導致頁面高度突然拉長（發生累積版面配置位移 CLS），影響閱讀體驗。

AniBT 圖床在上傳後會自動解析圖片的真實像素寬高，並在產生 HTML 代碼時自動帶上 `width` 和 `height` 屬性。釋出說明渲染器會預先計算比例並留出占位空間，徹底杜絕正文跳動。

## 使用流程

圖床清單使用縮圖。縮圖正在產生、產生失敗或格式不支援時，卡片會顯示對應狀態；可以透過圖片直連檢視已上傳的圖片。

<Steps>
  <Step>
    ### 開啟圖床管理控制台
    登入後造訪你的字幕組控制台 `/groups/<slug>/image-host`，將準備好的海報或截圖拖曳至上傳區域。
  </Step>

  <Step>
    ### 選擇適用的引用格式
    上傳成功後，在圖片卡片上可一鍵複製多種格式的代碼：

    <Tabs items={['HTML (推薦防抖)', 'Markdown', 'BBCode', '圖片直鏈']}>
      <Tab value="HTML (推薦防抖)">
        自動包含寬度與高度屬性，在 AniBT 及支援 HTML 的釋出站中能完美防止頁面載入抖動：

        ```html title="防抖 HTML 代碼"
        <img src="https://i.anibt.net/image-host/2026/07/05/HbJqq/xxx.webp" width="1920" height="1080" alt="預覽圖" />
        ```
      </Tab>

      <Tab value="Markdown">
        適用於標準 Markdown 編輯器或 GitHub 風格的釋出說明：

        ```markdown title="Markdown 格式"
        ![預覽圖](https://i.anibt.net/image-host/2026/07/05/HbJqq/xxx.webp)
        ```
      </Tab>

      <Tab value="BBCode">
        適用於動漫花園（DMHY）、末日站（ACGNX）等基於傳統論壇系統的 BT 站：

        ```txt title="BBCode 格式"
        [img]https://i.anibt.net/image-host/2026/07/05/HbJqq/xxx.webp[/img]
        ```
      </Tab>

      <Tab value="圖片直鏈">
        以 `i.anibt.net` 開頭的標準 HTTPS 圖片直接存取位址：

        ```txt title="圖片直鏈"
        https://i.anibt.net/image-host/2026/07/05/HbJqq/xxx.webp
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step>
    ### 貼至釋出說明
    將複製的代碼貼至釋出頁面的「釋出說明（Notes）」中，點選頁面上的「預覽」按鈕即可即時檢視排版渲染效果。
  </Step>
</Steps>

## 圖片刪除與生命週期

如果圖片上傳有誤或不再需要，上傳者本人、字幕組 Owner / 管理員均可在圖床列表中發起刪除。

- 發起刪除後，介面會回傳 `202 Accepted` 並將刪除操作加入任務佇列。
- 刪除狀態流轉：

<Callout type="warn">
  刪除僅對 AniBT 官方節點及直鏈生效。直鏈在訪客瀏覽器中最多快取 1 天，已經開啟過該圖片的瀏覽器在刪除後最長 1 天內仍可能顯示舊複本。已被第三方站點轉載或下載的複本不受本站刪除控制。
</Callout>
