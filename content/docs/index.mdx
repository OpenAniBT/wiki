title: 开始使用
description: 欢迎使用 AniBT。了解如何作为字幕组发布资源、作为观众下载追番，或作为开发者使用开放 API。
---

AniBT 是面向动漫爱好者与字幕组的 BT 资源分发、索引与检索平台。

<Callout type="info">
  浏览全站资源、复制磁力、下载种子以及使用公开 RSS 均无需登录。仅当需要收藏番剧、管理个人订阅，或以字幕组成员身份发布资源时，才需要注册账号。
</Callout>

无论你是制作动漫资源的字幕组、寻找高清动画的追番党，还是开发相关工具的技术爱好者，都可以在这里找到对应的使用方式。

## 快速导航

<Tabs items={['字幕组工作流', '观众与追番', '开发者与 API']}>
  <Tab value="字幕组工作流">
    字幕组在 AniBT 提交一次发布后，后台会自动同步至全网各大 BT 站，并享有专属图床与 Tracker 通信支持。

    <Steps>
      <Step>
        ### 申请入驻
        注册主站账号后，通过邮件提交字幕组信息与以往作品证明，获取字幕组管理后台权限与发布专属 slug。详见 [申请入驻](/docs/apply)。
      </Step>
      <Step>
        ### 配置外站同步与 Tracker
        在字幕组控制台填入各 BT 分发站（萌番组、蜜柑计划、动漫花园、末日站、ACG.rip、Nyaa）的凭据。制种时加入 [AniBT Tracker](/docs/tracker)。详见 [站点同步](/docs/site-sync)。
      </Step>
      <Step>
        ### 发布资源
        在后台页面直接上传种子制种发布，或通过 [发布 API](/docs/open-api/releases-publish) 接入自动化压制发布脚本。支持发布前效果预览与专属图床配图。

        发布时，如果番剧搜索提示暂时不可用，请稍后重试；这不表示番剧不存在。已知 BGM ID 时，可直接用 ID 绑定番剧。

        普通编辑适用于番剧和其他类资源的元数据，不能添加、替换或移除原始种子。已有种子时，磁力链接必须保留同一 v1 `infohash`；可以修改 tracker、显示名称等附加参数。只有磁力链接的发布仍可修改磁力，但不能通过普通编辑附加种子。
      </Step>
    </Steps>
  </Tab>

  <Tab value="观众与追番">
    无需繁琐注册，开箱即用的动漫搜索与全自动追番体验。

    <Steps>
      <Step>
        ### 检索与下载
        在主站首页或番剧页面，可通过动画中文名、日文原名、Bangumi 词条或字幕组标签精准检索。每个资源详情页均提供磁力链接与标准 `.torrent` 文件下载。

        资源详情页、`/magnets`、番剧页面，以及点击番剧海报后展开的资源面板，都在点击按钮时才获取下载地址：

        - 「复制磁力链接」「打开磁力链接」：点击后获取磁力链接。获取失败时提示「下载地址不可用」。浏览器拒绝写入剪贴板时，点击提示中的「再次复制」；浏览器未能直接打开磁力链接时，点击提示中的「再次打开」。
        - 「下载种子」：直接下载 `.torrent` 文件。番剧页面和展开面板中的种子按钮也直接下载，不再跳转到资源详情页。
        - 文件列表：在资源详情页点击「查看文件列表」后加载，加载完成后显示文件数。

        番剧页面的「资源」页签有自己的地址 `/anime/<id>?tab=releases`，默认的「发布进度」页签是 `/anime/<id>`。`/magnets` 与字幕组主页「发布」页签的上一页、下一页是带 `cursor` 参数的链接，可以在新标签页打开或分享。字幕组「发布」页签的季度筛选也写在地址中（`season` 与 `year`，或 `all`），每页 20 条。分页链接失效时回到当前条件的第一页。
      </Step>
      <Step>
        ### RSS 订阅追番
        复制番剧专属的 [RSS 订阅链接](/docs/open-api/rss-anime)，填入 qBittorrent、Sonarr 或 FlexGet 等下载工具。新集数发布后，下载工具会自动拉取种子并开始下载。
      </Step>
      <Step>
        ### 个人订阅管理（可选）
        登录后，在番剧页面点击「订阅本作」，可按字幕组、字幕语言、分辨率、文件格式、字幕类型和标签筛选，再点击「订阅」。不限制的条件保持「全部」。

        修改时，在番剧页面或「我的订阅」的番剧卡片上打开「订阅设置」。已有条件会自动填入，可先修改；其他筛选选项会继续加载，加载失败时可重试，已修改的条件会保留。点击「保存」后生效；点击「取消」不会修改订阅。同一筛选项内多选匹配任一选项，不同筛选项需同时满足。

        在「我的订阅」复制[个人订阅 RSS](/docs/open-api/rss-subscriptions) 的完整链接，即可在下载工具中接收符合条件的资源。个人链接包含访问凭证，请勿公开；番剧页面的公开 RSS 链接不使用个人筛选条件。
      </Step>
    </Steps>
  </Tab>

  <Tab value="开发者与 API">
    全站数据公开透明，提供规范的 REST API 与标准 RSS 输出。

    <Steps>
      <Step>
        ### 探索公开端点
        所有读取接口无需申请 Token 或配置鉴权，涵盖番剧查询、搜索召回、字幕组目录与最新磁力聚合。详见 [开放 API 总览](/docs/open-api)。
      </Step>
      <Step>
        ### 启用 304 条件请求
        公开端点全面支持弱 ETag 与 `If-None-Match`。在轮询脚本中携带 ETag 即可在内容无变更时直接返回 `304 Not Modified`，大幅节省网络开销。详见 [HTTP 缓存](/docs/open-api/caching)。
      </Step>
      <Step>
        ### 字幕组自动化接入
        持有字幕组 API Key 的开发者可通过 REST API 完成资源发布、元数据核对、外站同步状态追踪与资源撤回。
      </Step>
      <Step>
        ### 抓取与站点地图
        主站 `robots.txt`、站点地图分片、各类页面的收录规则、三种语言地址的互指（hreflang）和 IndexNow 通知见 [LLM 与 Agent 对接](/docs/llm)。
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 界面语言

AniBT 主站有简体中文、繁体中文和英文三种界面语言。页面语言只由地址决定，三种地址一一对应。

<TypeTable
  type={{
    '简体中文': {
      type: '不带前缀',
      description: '例：https://anibt.net/anime/617123',
    },
    '繁體中文': {
      type: '/zh-hant/',
      description: '例：https://anibt.net/zh-hant/anime/617123',
    },
    'English': {
      type: '/en/',
      description: '例：https://anibt.net/en/anime/617123',
    },
  }}
/>

- 每个页面都有三种地址，包括公开页面、登录与注册页面、个人页面和字幕组后台。在繁体中文或英文页面登录后，会回到同一语言的页面。
- 语言菜单中的其他语言链接到当前页面的对应地址，并记住你的选择。手动选择的语言优先于浏览器语言。
- 在当前标签页首次直接打开首页 `/` 时，网站先使用已记住的语言，再按浏览器语言列表选择支持的语言：英文进入 `/en`，繁体中文进入 `/zh-hant`；简体中文或没有匹配语言时留在 `/`。`en-US`、`en-GB` 按英文处理，`zh-TW`、`zh-HK`、`zh-MO` 按繁体中文处理。
- 每个标签页最多自动检测一次。同一标签页再次直接打开 `/` 时会保留简体首页；从详情页通过站内链接返回首页也不会触发检测。带语言前缀的地址和其他页面始终按地址显示对应语言。
- 自动跳转需要浏览器允许运行脚本和使用会话存储，跳转前可能短暂显示简体首页。被识别为爬虫或自动化工具的访问不参与自动跳转。需要其他语言时，随时可以使用语言菜单。
- 没有自动跳转时，以前选过繁体中文或英文的读者打开不带前缀的页面，会看到一次切换提示。点击「切換」或「Switch」打开同一页面的对应语言地址；不点击时保持当前页面。
- 主站的语言前缀只用小写，`/zh-Hant/…`、`/EN/…` 返回 404。本 Wiki 的繁体地址 `/zh-Hant/docs/…` 是另一套规则。
- 界面文字随语言改变。发布标题、发布说明和字幕组名称在三种语言中都保持原文。
- 繁体中文页面中的番剧名称使用官方繁体译名；没有官方译名的番剧由简体名称自动转换为繁体，番剧简介同样自动转换。简体中文和英文页面显示简体中文的番剧名称和简介。
- API（`/api/…`）、RSS、Torznab、站点地图、`robots.txt`、发布预览链接、登录回调与 OAuth 授权地址只有一个地址，不带语言前缀。
