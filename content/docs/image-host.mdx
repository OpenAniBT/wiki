AniBT 为入驻字幕组提供专属的图片托管服务，方便在发布动画资源时上传高清海报、剧集预览截图以及版本说明图。

<Callout type="info">
  图床服务仅对字幕组成员开放，入口位于控制台 `/groups/<slug>/image-host`。支持主流常见图片格式，单张上传上限为 **10 MiB**。
</Callout>

## 图片上传与排版防抖

发布页面如果直接引用无尺寸信息的外部图床图片，当用户网络较慢时，图片加载完成后会导致页面高度突然拉长（发生累积布局偏移 CLS），影响阅读体验。

AniBT 图床在上传后会自动解析图片的真实像素宽高，并在生成 HTML 代码时自动带上 `width` 和 `height` 属性。发布说明渲染器会预先计算比例并留出占位空间，彻底杜绝正文跳动。

## 使用流程

图床列表使用缩略图。缩略图正在生成、生成失败或格式不支持时，卡片会显示对应状态；可以通过图片直链查看已上传的图片。

<Steps>
  <Step>
    ### 打开图床管理控制台
    登录后访问你的字幕组控制台 `/groups/<slug>/image-host`，将准备好的海报或截图拖拽至上传区域。
  </Step>

  <Step>
    ### 选择适用的引用格式
    上传成功后，在图片卡片上可一键复制多种格式的代码：

    <Tabs items={['HTML (推荐防抖)', 'Markdown', 'BBCode', '图片直链']}>
      <Tab value="HTML (推荐防抖)">
        自动包含宽度与高度属性，在 AniBT 及支持 HTML 的发布站中能完美防止页面加载抖动：

        ```html title="防抖 HTML 代码"
        <img src="https://i.anibt.net/image-host/2026/07/05/HbJqq/xxx.webp" width="1920" height="1080" alt="预览图" />
        ```
      </Tab>

      <Tab value="Markdown">
        适用于标准 Markdown 编辑器或 GitHub 风格的发布说明：

        ```markdown title="Markdown 格式"
        ![预览图](https://i.anibt.net/image-host/2026/07/05/HbJqq/xxx.webp)
        ```
      </Tab>

      <Tab value="BBCode">
        适用于动漫花园（DMHY）、末日站（ACGNX）等基于传统论坛系统的 BT 站：

        ```txt title="BBCode 格式"
        [img]https://i.anibt.net/image-host/2026/07/05/HbJqq/xxx.webp[/img]
        ```
      </Tab>

      <Tab value="图片直链">
        以 `i.anibt.net` 开头的标准 HTTPS 图片直接访问地址：

        ```txt title="图片直链"
        https://i.anibt.net/image-host/2026/07/05/HbJqq/xxx.webp
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step>
    ### 粘贴至发布说明
    将复制的代码粘贴至发布页面的「发布说明（Notes）」中，点击页面上的「预览」按钮即可实时查看排版渲染效果。
  </Step>
</Steps>

## 图片删除与生命周期

如果图片上传有误或不再需要，上传者本人、字幕组 Owner / 管理员均可在图床列表中发起删除。

- 发起删除后，接口会返回 `202 Accepted` 并将删除操作加入任务队列。
- 删除状态流转：

<Callout type="warn">
  删除仅对 AniBT 官方节点及直链生效。直链在访客浏览器中最多缓存 1 天，已经打开过该图片的浏览器在删除后最长 1 天内仍可能显示旧副本。已被第三方站点转载或下载的副本不受本站删除控制。
</Callout>
