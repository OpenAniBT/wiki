AniBT 是由动漫爱好者与开源技术贡献者维护的社区平台。如你在使用过程中遇到任何疑问、需要申请权限或处理版权事务，均可通过官方邮箱与我们取得联系。

<Callout type="info">
  **官方联络邮箱**：[support@anibt.net](mailto:support@anibt.net)
</Callout>

## 常见事务与邮件规范

为了帮助我们更快定位并协助你处理问题，建议按以下分类与规范发送邮件：

<Tabs items={['字幕组入驻 / 白名单', '技术故障与 API 排障', '版权处理与下架 (DMCA)', '功能建议与反馈']}>
  <Tab value="字幕组入驻 / 白名单">
    - **邮件主题**：`字幕组入驻申请 - <组名>` 或 `Nyaa代发白名单申请 - <组名>`
    - **发件邮箱**：务必使用在 AniBT 注册的主账号邮箱发送。
    - **必要内容**：组名、slug、作品简介、以往发布证明（花园/蜜柑等主页链接）。详见 [申请入驻指南](/docs/apply)。
  </Tab>

  <Tab value="技术故障与 API 排障">
    - **邮件主题**：`【故障反馈】<发生异常的页面或接口名>`
    - **必要内容**：
      1. 发生问题的具体 URL 或请求端点
      2. 调用的 curl 命令或请求体参数（请遮蔽私钥敏感信息）
      3. 接口返回的错误 JSON，尤其是其中的 `requestId` 字段；在网页上遇到错误时，复制提示末尾的「错误代码 · 请求 ID」，或错误页上「复制全部」得到的内容
      4. 发生问题的时间（精确到分钟）
  </Tab>

  <Tab value="版权处理与下架 (DMCA)">
    - **邮件主题**：`DMCA Takedown Notice - <资源名称>`
    - **必要内容**：版权所有者证明文件、授权证明、涉及侵权的 AniBT 资源详情页完整链接，以及权利人的法定联系方式。我们将在核实后依法迅速处理。
  </Tab>

  <Tab value="功能建议与反馈">
    - **邮件主题**：`【建议】<你的想法概括>`
    - **必要内容**：欢迎提出关于站点使用体验、RSS 过滤功能、多站同步优化等任何建议。如果是针对开源生态工具的改进，也可以直接前往对应的 GitHub 仓库提出 Issue。
  </Tab>
</Tabs>

## 处理与回复时效

- **常规事务**：通常在 **1 至 3 个工作日** 内完成核实并回复。
- **版权下架**：收到完备材料后将在工作日 **24 小时内** 优先响应与处理。
- **排队提醒**：若超过 7 天未收到任何回信，请先查看邮箱的「垃圾邮件箱」是否误拦截；确认未收到后可发送邮件跟进。
