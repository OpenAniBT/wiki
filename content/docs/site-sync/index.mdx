AniBT 核心支持「一处发布、多站自动同步」能力。字幕组只需在 AniBT 提交一次资源，系统即可在后台自动将种子、标题、分类与发布说明分发至各大主流动漫 BT 站点。

<Callout type="info">
  站点同步为字幕组专属功能，使用前需先完成 [字幕组入驻申请](/docs/apply)。凭据在字幕组控制台 `/groups/<slug>/sync` 按站点独立配置，并通过安全加密存储。
</Callout>

## 同步机制与状态追踪

在 AniBT 成功提交发布后，系统后台会自动为每个启用的同步站点派发异步发布任务：

<Steps>
  <Step>
    ### 保存并测试凭据
    首次使用前，进入控制台 `/groups/<slug>/sync`，分别配置各站点的账号或 API Token。每个站点均提供「测试连接」按钮，请务必测试通过后再进行正式发布。
  </Step>

  <Step>
    ### 发布时自动派发
    正常发布番剧或其它资源时，系统会自动携带已启用的外站配置。在后台异步队列中，各个站点的提交互相独立，单个站点的网络波动不会影响本站及其他站点的正常发布。
  </Step>

  <Step>
    ### 查看状态与重试
    发布后，在字幕组资源列表点击「外站同步」状态徽章，可查看各站点的同步进度、外站详情页链接以及失败报错。某站提交失败时，字幕组成员可点击「重试同步」，重新提交失败的那一次。该站已有任务在排队或执行时，重试会被拒绝，连点不会重复提交。

    结果待核实（ambiguous）的记录可能已经发到外站，因此不提供重试，界面仍显示为失败。先到外站核实；确认需要再次提交时，由字幕组所有者、管理员或站点管理员使用「补发」。补发会再次提交此资源，外站可能出现重复内容。
  </Step>
</Steps>

同步日志在有任务排队或运行时约每 5 秒更新，空闲时约每 30 秒检查一次。从其他页面或设备发起的新任务，可能需要等到下一次检查才出现在当前页面；这不影响任务在后台开始执行。

## 常见同步状态说明

在管理后台或通过 [同步状态 API](/docs/open-api/releases-sync-status) 查询时，各站点返回的状态含义如下：

<TypeTable
  type={{
    'not_started': { type: '状态', description: '该站点未在后台启用同步，或本次发布未勾选该站。' },
    'pending': { type: '状态', description: '正在后台队列中排队或正在向目标站点提交上传。' },
    'success': { type: '状态', description: '外站已成功受理发布，响应中包含该资源在外站的详情页 URL。' },
    'failed': { type: '状态', description: '外站提交失败，通常由于凭据失效、分类错误或对方站点网络维护导致。' },
    'ambiguous': { type: '状态', description: '提交后未收到外站的明确确认，资源可能已经发到外站。系统不会自动重试，控制台也不提供重试；核实后由字幕组所有者、管理员或站点管理员补发。' },
  }}
/>

<Callout type="warn">
  开坑认领（将番剧与本字幕组绑定、自动匹配标题模板）位于控制台 `/groups/<slug>/claims`，不在站点同步设置中。
</Callout>
