AniBT 核心支援「一處釋出、多站自動同步」能力。字幕組只需在 AniBT 提交一次資源，系統即可在後台自動將種子、標題、分類與釋出說明分發至各大主流動漫 BT 站點。

<Callout type="info">
  站點同步為字幕組專屬功能，使用前需先完成 [字幕組入駐申請](/zh-Hant/docs/apply)。憑據在字幕組控制台 `/groups/<slug>/sync` 按站點獨立設定，並透過安全加密儲存。
</Callout>

## 同步機制與狀態追蹤

在 AniBT 成功提交釋出後，系統後台會自動為每個啟用的同步站點派發非同步釋出任務：

<Steps>
  <Step>
    ### 儲存並測試憑據
    首次使用前，進入控制台 `/groups/<slug>/sync`，分別設定各站點的帳號或 API Token。每個站點均提供「測試連線」按鈕，請務必測試通過後再進行正式釋出。
  </Step>

  <Step>
    ### 釋出時自動派發
    正常釋出番劇或其它資源時，系統會自動攜帶已啟用的外站設定。在後台非同步佇列中，各個站點的提交互相獨立，單個站點的網路波動不會影響本站及其他站點的正常釋出。
  </Step>

  <Step>
    ### 檢視狀態與重試
    釋出後，在字幕組資源列表點選「外站同步」狀態徽章，可檢視各站點的同步進度、外站詳情頁連結以及失敗報錯。某站提交失敗時，字幕組成員可點選「重試同步」，重新提交失敗的那一次。該站已有任務在排隊或執行時，重試會被拒絕，連點不會重複提交。

    結果待確認（ambiguous）的記錄可能已經發到外站，因此不提供重試，介面仍顯示為失敗。先到外站核實；確認需要再次提交時，由字幕組所有者、管理員或站點管理員使用「補發」。補發會再次提交此資源，外站可能出現重複內容。
  </Step>
</Steps>

同步日誌在有工作排隊或執行時約每 5 秒更新，閒置時約每 30 秒檢查一次。從其他頁面或裝置發起的新工作，可能需要等到下一次檢查才出現在目前頁面；這不影響工作在後台開始執行。

## 常見同步狀態說明

在管理後台或透過 [同步狀態 API](/zh-Hant/docs/open-api/releases-sync-status) 查詢時，各站點回傳的狀態含義如下：

<TypeTable
  type={{
    'not_started': { type: '狀態', description: '該站點未在後台啟用同步，或本次釋出未勾選該站。' },
    'pending': { type: '狀態', description: '正在後台佇列中排隊或正在向目標站點提交上傳。' },
    'success': { type: '狀態', description: '外站已成功受理釋出，回應中包含該資源在外站的詳情頁 URL。' },
    'failed': { type: '狀態', description: '外站提交失敗，通常由於憑據失效、分類錯誤或對方站點網路維護導致。' },
    'ambiguous': { type: '狀態', description: '提交後未收到外站的明確確認，資源可能已經發到外站。系統不會自動重試，控制台也不提供重試；核實後由字幕組所有者、管理員或站點管理員補發。' },
  }}
/>

<Callout type="warn">
  開坑認領（將番劇與本字幕組綁定、自動匹配標題範本）位於控制台 `/groups/<slug>/claims`，不在站點同步設定中。
</Callout>
