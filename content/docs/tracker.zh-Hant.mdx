AniBT 運行著專為本站釋出的動漫資源提供高速對等連線服務的自建 BitTorrent Tracker。

<Callout type="warn">
  **白名單通訊機制**：為了防範惡意刷流與垃圾種子濫用，AniBT Tracker 啟用了 infohash 白名單機制。只有在 AniBT 成功釋出的種子才會自動加入通訊白名單。未在本站釋出的種子回報時會回傳 `not whitelisted`。
</Callout>

## 官方 Tracker 位址

在製作 `.torrent` 檔案或在下載客戶端中設定 Tracker 時，請使用以下標準位址：

```txt title="AniBT Tracker Announce URL"
https://tracker.anibt.net/announce
```

- **通訊協定**：使用 HTTPS（連接埠 443）連線。
- **目前無法使用**：UDP 尚未啟用；公開 `/scrape` 與歷史 `/announce/v1/*` 路徑保持關閉。

## 檢視運作狀態

造訪 [Tracker 狀態頁](https://tracker.anibt.net/) 檢視做種節點、下載節點、記錄種子、累計完成和連線數量。可切換近 30、60、90 分鐘的歷史，以及節點、種子、完成記錄和連線檢視。

資料每分鐘更新。快照過期或無法取得時會明確提示；缺失資料顯示 `—`，圖表不補造歷史。節點按每個種子計數，不等於獨立使用者人數。連線數量包含等待連線，不等於做種或下載人數。

所選時間區間保留完整跨度，缺失區間以陰影標記，曲線不會跨過缺口。每張圖標明有效取樣數量與實際取樣範圍；回報平均值只計算有效樣本。

縱軸預設「從零」開始。查看累計完成數等指標的小幅變化時，可切換「自適應」；圖下會標明縱軸起點。累計完成仍表示累計數量。

移動指標或在手機上輕點圖表可查看精確時間與數值；點到缺口會提示沒有取樣。圖表取得焦點後，按左右方向鍵逐點查看，<kbd>Home</kbd> / <kbd>End</kbd> 跳到首尾，<kbd>Esc</kbd> 離開。展開「查看取樣明細」可讀取目前區間的逐筆記錄。

## 製種與釋出流程

<Steps>
  <Step>
    ### 在製種工具中新增 Tracker
    使用 qBittorrent、Transmission、mktorrent 等製種工具建立種子時，將 `https://tracker.anibt.net/announce` 填入 Tracker 伺服器列表第一行。
  </Step>

  <Step>
    ### 在 AniBT 平台提交釋出
    透過字幕組後台頁面或 [釋出 API](/zh-Hant/docs/open-api/releases-publish) 上傳產生的 `.torrent` 檔案。平台成功受理入庫後，會自動將該種子的 infohash 寫入 Tracker 通訊白名單，同時產生攜帶該 Tracker 的磁力連結。
  </Step>

  <Step>
    ### 客戶端做種上傳
    在下載客戶端中載入該種子，確認 Tracker 狀態顯示為 `working`（正常通訊）。此後其他從 AniBT 取得磁力或種子的觀眾即可透過該 Tracker 與你建立對等連線。
  </Step>
</Steps>

## 種子檔案下載介面

AniBT 為全站公開資源提供直接的 `.torrent` 二進位檔案下載路徑，第三方工具與腳本可按需呼叫：

<TypeTable
  type={{
    '番劇資源種子': {
      type: 'GET',
      description: 'https://anibt.net/api/torrent/{releaseId}.torrent（releaseId 以 rel_ 開頭）',
    },
    '其他類資源種子': {
      type: 'GET',
      description: 'https://anibt.net/api/other-torrent/{releaseId}.torrent（releaseId 以 orel_ 開頭）',
    },
  }}
/>

## 做種統計介面

依資源 ID 批次查詢做種數、下載數和完成數。無需登入，允許跨網域呼叫。請求和回應都不包含 infohash。

<Callout title="POST https://anibt.net/api/tracker-stats/batch">
  請求本文為 JSON，在 `releases` 中列出要查詢的資源。
</Callout>

```json title="請求範例"
{
  "releases": [
    { "kind": "release", "releaseId": "rel_dE7jiWrXPwPw" },
    { "kind": "other-release", "releaseId": "orel_wiki_audit_missing" }
  ]
}
```

<TypeTable
  type={{
    'releases': {
      type: 'array',
      description: '要查詢的資源，最多 200 項。重複項只計一次；預設只回傳前 60 個不同資源，其餘資源不會出現在回應中。',
    },
    'releases[].kind': {
      type: '"release" | "other-release"',
      description: '番劇資源（ID 以 rel_ 開頭）填 release，其他類資源（ID 以 orel_ 開頭）填 other-release。',
    },
    'releases[].releaseId': {
      type: 'string',
      description: '資源 ID，1–180 個字元。',
    },
  }}
/>

回應的 `statsByRelease` 依 `kind` 和資源 ID 分組，`release` 與 `other-release` 兩組始終存在。`now` 為伺服器時間，單位為 Unix 毫秒。

```json title="回應範例"
{
  "statsByRelease": {
    "release": {
      "rel_dE7jiWrXPwPw": {
        "state": "fresh",
        "seeders": 53,
        "leechers": 44,
        "completed": 64,
        "updatedAt": 1791023419906,
        "refreshQueued": false
      }
    },
    "other-release": {
      "orel_wiki_audit_missing": { "state": "unavailable" }
    }
  },
  "now": 1791023794205
}
```

<TypeTable
  type={{
    'state': {
      type: '"fresh" | "stale" | "missing" | "unavailable"',
      description: 'fresh：近期測得。stale：測得時間較早，數字仍有效，以 updatedAt 為準。missing：資源公開，但還沒有測量結果；不含計數，不表示 0。unavailable：資源不存在、已刪除、未公開或沒有種子資訊；只含 state。',
