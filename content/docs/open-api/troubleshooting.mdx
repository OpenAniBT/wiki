应用 JSON 错误的追踪值是 `error.requestId`，响应头通常也有 `X-Request-ID`。纯文本、XML、重定向或边缘响应不保证携带该字段。反馈时提供端点、时间、HTTP 状态和可用的请求 ID，不要附带 Key、Cookie 或私人 RSS URL。

有权限再次 DELETE 已删除的发布时，返回原来那一次删除操作。若 DELETE 返回 404，表示资源从未存在、属于其他字幕组，或当前 Key 无权删除（普通成员的 Key 删除同组其他成员发布的资源时，响应与资源不存在时相同），不要据此认定删除完成；可用同一 releaseId 查询 `/deletion`。
