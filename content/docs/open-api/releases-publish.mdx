          番剧发布必须指定 animeIdType 与 animeId，不按标题匹配番剧。 Idempotency-Key 从首次受理起绑定完整请求。同键改参返回 409 CONFLICT；缺少绑定的旧未完成上传请求返回 legacy_request_binding_missing，两者均须使用新键。重放及 503 重试规则见「接口约定与鉴权」。
          animeId 按来源规范化：接受全角数字、前导零和该来源站点的番剧链接（bgm.tv / bangumi.tv / chii.in、myanimelist.net、anidb.net、anilist.co）。已合并的旧 BGM ID 发布到合并后的番剧。发布只解析站内已收录的番剧，不会新收录。
          bgm 的 animeId 不是 ID 时返回 422；mal、anidb、anilist 的 animeId 不是 ID、站内没有，或只有被管理员隐藏、被 bgm.tv 标记为 NSFW 的番剧持有该 ID 时返回 404；同一个外部 ID 对应多部公开番剧时返回 422（Anime identifier is ambiguous），请改用 bgm ID。
          multipart 必须上传 torrent，title 省略时使用种子内部名；JSON 必须提供 title 和属于当前字幕组的 torrentStorageId。JSON 还必须提供 magnetBase64。
          成功发布返回 { ok: true, result: { releaseId, revision, torrentObjectId? } }。发布回执不包含 groupId、groupName、groupSlug、animeId 或 fileSize；发布前用 GET 同一路径核验身份。
          preview=true 返回顶层 previewUrl、previewToken、expiresAt 和 Key 身份信息，10 分钟后过期；不创建公开发布。
          未显式提供的集数、画质、语言、字幕、格式和版本先从标题、再从种子内部名推断；无法推断集数时需传 episode 或 episodeKey。
          notes 最多 50000 字符。JSON 请求上限默认 1 MiB，multipart 默认 8 MiB，单个 .torrent 文件最多 5 MiB。
          Nyaa 需要字幕组白名单和有效分类，种子必须包含 http://nyaa.tracker.wf:7777/announce。Nyaa 代发应使用 multipart，确保从上传种子提取 tracker。
          Nyaa 的结构化 sitePublish.nyaa 仅用于 JSON；multipart 使用 nyaa、nyaaCategory、nyaaComplete 等独立字段。
          200 表示本站发布已写入，不保证外站同步或下游读取已经完成。
          发布请求达到限额时返回 429 RATE_LIMIT_EXCEEDED。发布暂时繁忙、限流服务不可用或上传结果仍待确认时，可返回 503 SERVICE_UNAVAILABLE；限流拒绝发生在发布前，其他失败不能据此推断未写入。响应带 Retry-After 时按其秒数等待；没有该头时先核查现有发布并保留 error.requestId，不要立即批量重试。
          普通发布可发送 Idempotency-Key（去除首尾空白后为 1–256 字符）。同一 API Key、同一发布端点的同一请求重试复用原值；已成功的命令返回原回执，不重复发布。即使原资源已删除，旧命令仍返回旧回执，不恢复资源。删除后有意重新发布时使用新的 Idempotency-Key；从首次受理开始，同一键绑定完整请求；切换发布与预览，或改变资源内容、Nyaa 选项、显式发布时间、上传文件时，请使用新键。同键改参返回 409 CONFLICT，上传完成或已有回执不能绕过绑定。
          升级前已上传但尚未完成的请求若缺少完整绑定，返回 409 CONFLICT，error.reason 为 legacy_request_binding_missing；请使用新键重新提交完整请求。已完成的旧请求仍按原回执重放。
          Idempotency-Key 未提供、为空或超过 256 字符时，本次请求按新命令处理，不能依赖命令回放。跨站浏览器预检目前不允许此请求头；需要该重试保证的客户端应从服务端调用。
