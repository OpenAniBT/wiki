          Sonarr、Radarr、Prowlarr 的匿名 Torznab 入口。客户端 URL 为
          https://anibt.net/torznab，API Path 为 /api。

          不需要 API Key，apikey 参数会被忽略。支持 GET、HEAD；响应 no-store。

          t=caps 返回能力 XML；search、tvsearch、movie 返回 RSS XML。协议参数错误仍返回 HTTP 200 的
          <error> XML，不能只按 HTTP 状态判断成功。

          不支持 TVDB/TMDB/IMDb/rid/tvmazeid 检索，提供这些 ID 会返回空列表。关键词最多 160 UTF-8
          字节、16 个正向词和 8 个排除词，超出时返回错误 201。search/tvsearch 的尾部 2–4 位数字可作为集数；尾部
          1900–2099 按年份移除。movie 仅移除年份。

          关键词按「开放 API 总览」的「资源搜索」匹配，结果固定按发布时间倒序。指定集数或剧场版分类（cat 含 2000 或 2020 且不含
          5000 或 5070）时，先按这些条件过滤，再取最新的 100 条。只有分隔符、符号或排除词的 q 返回空列表。

          limit 默认 100，上限 100；最新列表 offset + limit 最多 300，关键词搜索最多
          100；超出窗口返回空列表。默认 60 次 / 60 秒 / IP。

          带关键词时 total 是这次搜索最多 100 条结果的条数，不是全部匹配数，在窗口内不随 limit 和 offset 变化。不带关键词时
          total 可能是估算值。limit=0、超出窗口、提供 ID 或分类全部未知的请求先返回 total 为 0 的空列表，不检查词数。
