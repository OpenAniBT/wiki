## 番剧查询与评分

`/api/seasons/anime` 的 `scope.kind` 区分季度浏览、关键词搜索和精确 ID 查询。全库关键词搜索的 `requestedSeason` 为 `null`，每部作品使用自己的季度；首播日期与季度分类分开。`premiere.precision` 为 `day`、`month`、`season` 或 `year`，粗精度日期使用周期首日。

季度浏览最多返回 200 条，关键词搜索最多 50 条。`total` 是本次返回数，`truncated=true` 表示还有结果；完整翻页使用 `/api/animes/search`，规则见[番剧搜索](#番剧搜索)。`rating` 使用 0–10 分，缺有效来源评分时返回 `5.0`；`averageScore` 使用 0–100 分，对应默认 `50`。现有 ani-rss 可直接排序，但旧版本不读取截断提示，仍最多显示 50 条搜索结果。

默认评分会在后续同步取得有效来源评分时自动更新；人工锁定的评分保留。资料更新沿用既有同步频率，浏览页面或订阅 RSS 不会逐条刷新上游资料。

## 番剧搜索

`/api/animes/search`、`/search`、`/api/bgm/search` 和 `/api/seasons/anime` 的 `query` 使用同一套标题搜索，比较番剧的每个标题和别名。

比较前统一大小写和全半角，把片假名折叠为平假名，把繁体和日文新字体折叠为简体，再忽略空格和标点。`ふりーれん` 能找到片假名标题，`進擊` 能找到简体标题。

匹配结果分级排名，同级按热度降序，再按番剧 ID 升序：

1. **完全相等**：某个标题或别名与查询相同。
2. **前缀**：某个标题或别名以查询开头。
3. **子串**：某个标题或别名包含查询。
4. **多词**：每个词都命中同一部番剧的某个标题或别名，顺序不限，可以分散在不同标题里。只在查询有 2–16 个词时使用；词更多时跳过这一级，不报错。
5. **字序**：2–4 个中日文字符按顺序出现在同一个标题或别名里，可以不连续。`进巨` 能找到「进击的巨人」。
6. **相似度**：拼写相近的标题或别名。

`/api/animes/search`、`/search` 和 `/api/bgm/search` 按这个排名返回。`/api/seasons/anime` 只用它选出最多 50 部番剧，响应仍按星期分组，组内按播出时间和标题排序。

限制：

- 拼写容错只来自相似度。长标题能容忍少量拼写差异，例如 `kimetu no yaiba`；短单词的字母换位可能找不到，例如 `freiren`。
- 所有标点都是分隔符，`Re:Zero` 和 `Re Zero` 是同一个查询。年份没有单独的规则，与其他词一样匹配。
- 1–2 个字符的查询不做子串和相似度匹配。能否匹配某个标题或别名，取决于两者的关系：
  - 查询与整个标题或别名相同（忽略空格和标点）时总能匹配。
  - 拉丁字母和数字：要是其中完整的词或词的开头。`rk`、`or` 不匹配词中间的字母。
  - 中日文：要是其中的单字或相邻的两个字。查询里的标点先被移除，所以 `ス・ダ` 匹配这两个假名相邻的标题或别名，不匹配标题或别名里被标点隔开的这两个假名（整个标题或别名恰好是这两个假名时除外）。不含空格和标点的两个字还可以按上面的字序匹配。
  - 中日文和字母或数字混排（`人0`）：只匹配相同的完整片段，也就是被空格或标点隔开的一段。
- 折叠后为空的查询（例如 `☆★`）返回空的最后一页。

### 番剧搜索的分页

`/api/animes/search` 接受 `q`、`format`、`status`、`seasonYear`、`limit`（默认 24，1–50）和 `cursor`，直接返回 `page`、`isDone`、`continueCursor`，没有 `ok` 或 `data` 包装。

<Callout type="warn">
  `continueCursor` 是不透明的令牌，最后一页为空字符串。翻页时原样传回，不要解析或自行拼接。
</Callout>

以下 `cursor` 返回 422 `VALIDATION_ERROR`：

- 自行拼接的 `ts_page:N` 和其他格式错误的值；
- 不是为相同的查询、过滤条件和搜索规则签发的值；
- 和空查询一起发送的值。

2026 年 10 月 31 日更新之前签发的 cursor 已全部失效。收到 422 时去掉 `cursor`，从第一页重新开始。

## 资源搜索

`/magnets?q`、番剧页的资源搜索、其他类资源分类、`/rss/magnets.xml?q=`、`/rss/other/<category>.xml?q=` 和 `/torznab/api?q=` 按以下规则匹配。每个词都必须命中，不纠错、不补全前缀，也不丢词（`/magnets?q` 的例外见[放宽搜索](#magnets-的放宽搜索)）：

- 番剧资源比较自己的标题与规格（集数标记、分辨率、格式、字幕类型、语言），以及所属番剧的每个标题和别名。不同的词可以命中不同位置，番剧的任一别名都能找到只有其他语言标题的资源。
- 其他类资源只比较自己的标题和分类。
- 拉丁字母和数字要是完整的词：`HEV` 找不到 `HEVC`，`1080` 找不到 `1080p`，`LoliHous` 找不到 `LoliHouse`。
- 中日文按连续字符匹配，不要求是完整的词：`鬼灭` 能找到《鬼灭之刃》的资源。
- 字母和数字在每个入口都不区分大小写和全半角，假名和繁简体的折叠方式与番剧搜索相同。

结果只按所选排序列出，默认最新发布在前，没有相关度排序。Torznab 固定按发布时间倒序。

严格匹配的第一页为空时，才运行一次拆词或合词回退：`Loli Hose` 能找到 `LoliHose`，`rezero` 能找到 `Re:ZERO`，`Re:Zero` 能找到 `ReZero`。回退只放宽相邻词的边界，不放宽排除词，后续页沿用第一页的匹配方式。

### `/magnets` 的放宽搜索

`/magnets?q` 的番剧资源，在严格匹配和上面的拆词或合词回退之后第一页仍为空时，会再放宽搜索一次，页面上会提示这是放宽后的结果。排序不变，也不丢词。依次尝试，先有结果的生效：

1. **词前缀：** 一个词的最后一段如果不含数字、至少 3 个字符，可以只写开头：`HEV` 能找到 `HEVC`，`LoliHous` 能找到 `LoliHouse`。含数字的部分不补全，`1080` 还是找不到 `1080p`。
2. **番剧标题相似度：** 尝试匹配番剧标题里的单处拼写差异：`kimetu no yaiba` 能找到《鬼灭之刃》的资源。不含数字的词连起来至少要 6 个字符（全是中日文时至少 4 个），含数字的词不计入，更短的查询不走这一步。含数字的词、1–3 个字符的词，以及引号短语这类由多个部分组成的词仍必须严格命中：`kimetu no yaiba 1080p` 只列出 1080p 的资源，`kimetsu no yaiba 2160p` 在没有 2160p 资源时仍是空的，`"kimetu no yaiba"` 加了引号也是空的。资源自身的文本（如字幕组名）没有这项容错。

第一页的放宽读取失败时，答复严格搜索的空结果，不返回错误；放宽结果翻页时失败，和其他搜索一样返回 503。番剧页的资源搜索、其他类资源分类、RSS 和 Torznab 始终按严格规则匹配，所以 `/magnets` 上放宽后才有结果的搜索词，在 RSS 里可能是空的。

### 标点、引号和排除

- 不含数字的词按标点拆开，各部分分别匹配：`Nix-Raws`、`Re:Zero`、`鬼灭/第二季` 都是两个词，可以一个命中番剧别名，另一个命中资源标题。
- 含数字且有多个部分的词是一个短语：`HEVC-10bit`、`x264-AAC`、`第2期` 的各部分必须在同一段文字（资源自己的标题与规格，或番剧的一个标题、别名）里相邻且顺序相同。`HEVC-10bit` 找不到 `10bit x264 HEVC`，`第2` 不匹配 `第20期`。
- 独立成词的完整引号短语是一个短语，可以含空格：`"25 1080p"`。引号贴着其他字符或没有闭合时，引号被忽略，其中的词按普通词处理。
- `-词` 是排除，只看资源自己的标题与规格，不看番剧别名。`-web-dl` 要求 `web` 和 `dl` 相邻且顺序相同，不排除写成一个词的 `WebDL`。`-"25 1080p"` 排除这个短语。
- 两侧有空白的 `-` 是分隔符：`Title - 25` 搜索 `25`，`Title -25` 排除 `25`。
- 排除和引号短语要使用半角的 `-` 和 `"`。全角的操作符在不同入口可能有不同的处理，不要依赖。

### 词数上限和空查询

一次查询最多 16 个正向词和 8 个排除词。引号短语和含数字的词算 1 个，`a/b/c` 算 3 个，分隔符和纯符号不计，每个排除词算 1 个。超出时各接口的响应：

### 资源搜索的分页

- `/magnets` 的分页链接失效时回到当前条件的第一页，包括 2026 年 10 月 31 日更新之前保存的搜索分页链接。
- RSS 没有分页，Torznab 使用有界 `offset`。

## 搜索暂不可用

## 播出状态

自动判定完结需要明确的首播日期和结束日期，并且来源在结束日完整过去后再次确认结束日期。日期按日本时间比较；只有年份、月份、季度或作品类型，不能据此判定完结。

来源更正播出计划后，自动状态会随同步重新计算。人工锁定的状态以及明确的停播、取消状态优先。证据不足的作品标为未知，不沿用缺乏依据的历史状态，也不把计划结束日当成已完结证明。

首页同一作品同一天只显示最新一集；正常跨日连播仍分别显示。
