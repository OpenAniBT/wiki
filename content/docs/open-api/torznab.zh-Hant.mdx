---
title: Torznab 介面
description: 在 Sonarr、Radarr、Prowlarr 中把 AniBT 新增為 Torznab 索引器，自動搜尋和抓取番劇資源。
---

AniBT 提供 Torznab 介面。Sonarr、Radarr 和 Prowlarr 可以直接把 AniBT 新增為索引器。

<Callout type="info">
  不需要註冊，也不需要 API Key。用戶端裡的 **API Key** 留空即可，介面不會讀取它。
</Callout>

<Callout title="GET /torznab/api">
  用戶端裡的 **URL** 填 `https://anibt.net/torznab`，**API Path** 保持預設的 `/api`。
</Callout>

## 新增索引器

<Tabs items={['Sonarr', 'Radarr', 'Prowlarr']}>
  <Tab value="Sonarr">
    <Steps>
      <Step>
        ### 新建索引器
        進入 **Settings** → **Indexers**，點選 **+**，選擇 **Torznab**。
      </Step>
      <Step>
        ### 填寫位址
        **URL** 填 `https://anibt.net/torznab`，**API Path** 保持 `/api`，**API Key** 留空。
      </Step>
      <Step>
        ### 選擇分類
        **Anime Categories** 選擇 `5070`（Anime）。**Categories** 可以清空。
      </Step>
      <Step>
        ### 測試並儲存
        點選 **Test**，通過後儲存。番劇的 **Series Type** 設為 **Anime**。
      </Step>
    </Steps>
  </Tab>

  <Tab value="Radarr">
    <Steps>
      <Step>
        ### 新建索引器
        進入 **Settings** → **Indexers**，點選 **+**，選擇 **Torznab**。
      </Step>
      <Step>
        ### 填寫位址
        **URL** 填 `https://anibt.net/torznab`，**API Path** 保持 `/api`，**API Key** 留空。
      </Step>
      <Step>
        ### 選擇分類
        **Categories** 選擇 `2000`（Movies）和 `2020`（Movies/Other）。Radarr 只會拿到劇場版資源。
      </Step>
    </Steps>
  </Tab>

  <Tab value="Prowlarr">
    <Steps>
      <Step>
        ### 新建索引器
        進入 **Indexers** → **Add Indexer**，搜尋並選擇 **Generic Torznab**。
      </Step>
      <Step>
        ### 填寫位址
        **URL** 填 `https://anibt.net/torznab`，**API Path** 保持 `/api`，**API Key** 留空。
      </Step>
      <Step>
        ### 同步到 Sonarr / Radarr
        Prowlarr 按分類同步：`5070` 同步給 Sonarr，`2000` 同步給 Radarr。
      </Step>
    </Steps>
    Prowlarr 和 Jackett 內建的「AniBT」定義讀取的是 RSS，做種數固定顯示為 1。建議改用 Generic Torznab。
  </Tab>
</Tabs>

## 搜尋規則

- 關鍵字按[資源搜尋](/zh-Hant/docs/open-api#資源搜尋)的規則比對：每個詞都必須命中資源標題與規格或所屬番劇的任一標題、別名，拉丁字母與數字要是完整的詞，不校正、不補全前綴。嚴格比對為空時才嘗試一次拆詞或合詞。
- `-詞` 排除資源自身標題與規格中含該詞的資源。只有分隔符、符號或排除詞的關鍵字回傳空列表。
- 結果固定按釋出時間倒序。
- 關鍵字結尾的 2 到 4 位數字按集數比對，例如 `Frieren 05`。只有 1 位數字時不當作集數。
- 關鍵字結尾的 1900 至 2099 按年份忽略，例如 `Suzume 2022`。
- 集數按字幕組標註的集數比對。分季重新計數的番劇，Sonarr 傳送的絕對集數可能比對不到後續季。
- 只有中文標題的資源也能用所屬番劇的英文或羅馬音別名搜到。番劇沒有對應別名時搜不到。
- 暫不支援按 TVDB、TMDB 或 IMDb ID 搜尋，這類請求回傳空結果。
- 指定集數或劇場版分類（`cat` 含 `2000` 或 `2020` 且不含 `5000` 或 `5070`）時，先按這些條件篩選，再取最新的 100 條。

## 常見問題

<Accordions>
  <Accordion title="Sonarr 測試失敗：no results in configured categories">
    **Anime Categories** 沒有選擇 `5070`。選擇後重新測試。
  </Accordion>
  <Accordion title="回傳 error code 203">
    不支援音樂和圖書搜尋。
  </Accordion>
  <Accordion title="回傳 error code 201">
    參數格式錯誤。例如 `cat` 不是用逗號分隔的數字，或關鍵字超過 160 個 UTF-8 位元組、16 個正向詞或 8 個排除詞。
  </Accordion>
</Accordions>
