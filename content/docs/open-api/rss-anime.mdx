          主入口。`bgmId` 与 `groupSlug` 至少提供一个。兼容 Mikan 的 `bangumiId`、`subgroupid`。

          Tag 可重复或逗号分隔：`?resolution=1080p&resolution=720p` 与
          `?resolution=1080p,720p` 等价。

          非法 `limit` 返回应用 `400`，生产边缘可能先 `403`。与默认值等价的写法会 `308` 到规范 URL。

          bgm.tv 合并过的旧 `bgmId` 会 `308` 到把 `bgmId` 换成新 ID 的同一 URL，`groupSlug`
          等其他参数不变。恰好只有 `bgmId` 与 `groupSlug` 的订阅链接同样跳转，跟随即可，不必重新订阅。目标番剧暂时无法解析时返回
          `503`（`Cache-Control: no-store`），不返回 `404`。

          每个
          `<item>`：`<title>`、`<link>`（`/release/<id>`）、`<guid>`、`<pubDate>`（RFC
          822，`+0800`）、`<enclosure>` 种子下载链接、`<torrent>` infoHash、已绑定时
          `<anibt:bgmId>`。

          `limit` 默认 100，上限 100。速率限制默认 120 次 / 60 秒 / IP。

          浏览器直开返回原生 XML。搜索引擎不抓 `/rss/`。

          成功响应为 application/xml，enclosure 指向 .torrent 文件；错误正文通常为纯文本。GET 与 HEAD
          支持 If-None-Match。
