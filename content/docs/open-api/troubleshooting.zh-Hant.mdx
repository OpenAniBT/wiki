應用程式 JSON 錯誤的追蹤值是 error.requestId，回應標頭通常也有 X-Request-ID。純文字、XML、重新導向或邊緣回應不保證攜帶此欄位。回報時提供端點、時間、HTTP 狀態和可用的請求 ID，不要附帶 Key、Cookie 或私人 RSS URL。

有權限再次 DELETE 已刪除的釋出時，回傳原來那一次刪除操作。若 DELETE 回傳 404，表示資源從未存在或目前呼叫方無權存取，不要據此認定刪除完成；可用同一 releaseId 查詢 `/deletion`。
