          按 bgmId 查询字幕组，每组返回最近 30 条资源，并提供 publishedEpisodes、progressEpisodes 和
          totalReleases；data.seriesNumberMap 是番剧的系列编号对照。

          publishedEpisodes 是字幕组标注的正片集数，原样列出。progressEpisodes 是 AniBT
          发布进度为该组点亮的本季集数：按系列编号标注后续季的字幕组（第三季写 49–54）在这里是 1–6。

          seriesNumberMap 的每一项 { seriesFrom, seriesTo, episodeFrom } 表示系列编号
          seriesFrom 到 seriesTo 依次是本季从 episodeFrom 开始的各集，对照来自 bgm.tv；番剧没有这种编号时为
          []。

          magnet、size、episodeKey、resolution、format、subtitle、lastUpdatedAt 可为
          null。subtitle 通常为 EXTERNAL / INTERNAL / EMBEDDED / NONE。

          已合并的旧 bgmId 返回合并后番剧的 animeId、标题和字幕组，data.bgmId 保持请求值。

          未找到番剧，或番剧被管理员隐藏、被 bgm.tv 标记为 NSFW 时返回 404；暂时无法提供完整结果时返回 503
          SEARCH_UNAVAILABLE，并带 Retry-After。

          支持 GET、HEAD 和 If-None-Match；默认与季度番剧接口共用 30 次 / 60 秒 / IP 的限额。

          支持 GET、HEAD、OPTIONS；条件请求仍可能消耗限流额度。
