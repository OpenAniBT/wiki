## 番劇查詢與評分

`/api/seasons/anime` 的 `scope.kind` 區分季度瀏覽、關鍵字搜尋與精確 ID 查詢。全庫關鍵字搜尋的 `requestedSeason` 為 `null`，每部作品使用自己的季度；首播日期與季度分類分開。`premiere.precision` 為 `day`、`month`、`season` 或 `year`，粗精度日期使用週期首日。

季度瀏覽最多回傳 200 筆，關鍵字搜尋最多 50 筆。`total` 是本次回傳數量，`truncated=true` 表示還有結果；完整分頁使用 `/api/animes/search`，規則見[番劇搜尋](#番劇搜尋)。`rating` 使用 0–10 分，缺有效來源評分時回傳 `5.0`；`averageScore` 使用 0–100 分，對應預設 `50`。現有 ani-rss 可直接排序，但舊版本不讀取截斷提示，仍最多顯示 50 筆搜尋結果。

預設評分會在後續同步取得有效來源評分時自動更新；人工鎖定的評分保留。資料更新沿用既有同步頻率，瀏覽頁面或訂閱 RSS 不會逐筆更新上游資料。

## 番劇搜尋

`/api/animes/search`、`/search`、`/api/bgm/search` 與 `/api/seasons/anime` 的 `query` 使用同一套標題搜尋，比對番劇的每個標題與別名。

比對前統一大小寫與全半形，把片假名摺疊為平假名，把繁體與日文新字體摺疊為簡體，再忽略空白與標點。`ふりーれん` 能找到片假名標題，`進擊` 能找到簡體標題。

比對結果分級排名，同級按熱度降序，再按番劇 ID 升序：

1. **完全相等**：某個標題或別名與查詢相同。
2. **前綴**：某個標題或別名以查詢開頭。
3. **子字串**：某個標題或別名包含查詢。
4. **多詞**：每個詞都命中同一部番劇的某個標題或別名，順序不限，可以分散在不同標題裡。只在查詢有 2–16 個詞時使用；詞更多時跳過這一級，不報錯。
5. **字序**：2–4 個中日文字元按順序出現在同一個標題或別名裡，可以不連續。`進巨` 能找到「進擊的巨人」。
6. **相似度**：拼寫相近的標題或別名。

`/api/animes/search`、`/search` 與 `/api/bgm/search` 按這個排名回傳。`/api/seasons/anime` 只用它選出最多 50 部番劇，回應仍按星期分組，組內按播出時間與標題排序。

限制：

- 拼寫容錯只來自相似度。長標題能容忍少量拼寫差異，例如 `kimetu no yaiba`；短單字的字母換位可能找不到，例如 `freiren`。
- 所有標點都是分隔符，`Re:Zero` 與 `Re Zero` 是同一個查詢。年份沒有單獨的規則，與其他詞一樣比對。
- 1–2 個字元的查詢不做子字串與相似度比對。能否比對到某個標題或別名，取決於兩者的關係：
  - 查詢與整個標題或別名相同（忽略空白與標點）時總能比對到。
  - 拉丁字母與數字：要是其中完整的詞或詞的開頭。`rk`、`or` 不比對詞中間的字母。
  - 中日文：要是其中的單字或相鄰的兩個字。查詢裡的標點先被移除，所以 `ス・ダ` 比對這兩個假名相鄰的標題或別名，不比對標題或別名裡被標點隔開的這兩個假名（整個標題或別名恰好是這兩個假名時除外）。不含空白與標點的兩個字還可以按上面的字序比對。
  - 中日文與字母或數字混排（`人0`）：只比對相同的完整片段，也就是被空白或標點隔開的一段。
- 摺疊後為空的查詢（例如 `☆★`）回傳空的最後一頁。

### 番劇搜尋的分頁

`/api/animes/search` 接受 `q`、`format`、`status`、`seasonYear`、`limit`（預設 24，1–50）與 `cursor`，直接回傳 `page`、`isDone`、`continueCursor`，沒有 `ok` 或 `data` 包裝。

<Callout type="warn">
  `continueCursor` 是不透明的權杖，最後一頁為空字串。翻頁時原樣傳回，不要解析或自行拼接。
</Callout>

以下 `cursor` 回傳 422 `VALIDATION_ERROR`：

- 自行拼接的 `ts_page:N` 與其他格式錯誤的值；
- 不是為相同的查詢、篩選條件與搜尋規則簽發的值；
- 和空查詢一起傳送的值。

2026 年 10 月 31 日更新之前簽發的 cursor 已全部失效。收到 422 時去掉 `cursor`，從第一頁重新開始。

## 資源搜尋

`/magnets?q`、番劇頁的資源搜尋、其他類資源分類、`/rss/magnets.xml?q=`、`/rss/other/<category>.xml?q=` 與 `/torznab/api?q=` 按以下規則比對。每個詞都必須命中，不校正、不補全前綴，也不丟詞：

- 番劇資源比對自己的標題與規格（集數標記、解析度、格式、字幕類型、語言），以及所屬番劇的每個標題與別名。不同的詞可以命中不同位置，番劇的任一別名都能找到只有其他語言標題的資源。
- 其他類資源只比對自己的標題與分類。
- 拉丁字母與數字要是完整的詞：`HEV` 找不到 `HEVC`，`1080` 找不到 `1080p`，`LoliHous` 找不到 `LoliHouse`。
- 中日文按連續字元比對，不要求是完整的詞：`鬼滅` 能找到《鬼滅之刃》的資源。
- 字母與數字在每個介面都不區分大小寫與全半形，假名與繁簡體的摺疊方式與番劇搜尋相同。

結果只按所選排序列出，預設最新釋出在前，沒有相關度排序。Torznab 固定按釋出時間倒序。

嚴格比對的第一頁為空時，才執行一次拆詞或合詞回退：`Loli Hose` 能找到 `LoliHose`，`rezero` 能找到 `Re:ZERO`，`Re:Zero` 能找到 `ReZero`。回退只放寬相鄰詞的邊界，不放寬排除詞，後續頁沿用第一頁的比對方式。

### 標點、引號與排除

- 不含數字的詞按標點拆開，各部分分別比對：`Nix-Raws`、`Re:Zero`、`鬼滅/第二季` 都是兩個詞，可以一個命中番劇別名，另一個命中資源標題。
- 含數字且有多個部分的詞是一個短語：`HEVC-10bit`、`x264-AAC`、`第2期` 的各部分必須在同一段文字（資源自己的標題與規格，或番劇的一個標題、別名）裡相鄰且順序相同。`HEVC-10bit` 找不到 `10bit x264 HEVC`，`第2` 不比對 `第20期`。
- 獨立成詞的完整引號短語是一個短語，可以含空白：`"25 1080p"`。引號貼著其他字元或沒有閉合時，引號被忽略，其中的詞按一般詞處理。
- `-詞` 是排除，只看資源自己的標題與規格，不看番劇別名。`-web-dl` 要求 `web` 與 `dl` 相鄰且順序相同，不排除寫成一個詞的 `WebDL`。`-"25 1080p"` 排除這個短語。
- 兩側有空白的 `-` 是分隔符：`Title - 25` 搜尋 `25`，`Title -25` 排除 `25`。
- 排除與引號短語要使用半形的 `-` 與 `"`。全形的操作符在不同介面可能有不同的處理，不要依賴。

### 詞數上限與空查詢

一次查詢最多 16 個正向詞與 8 個排除詞。引號短語與含數字的詞算 1 個，`a/b/c` 算 3 個，分隔符與純符號不計，每個排除詞算 1 個。超出時各介面的回應：

### 資源搜尋的分頁

- `/magnets` 的分頁連結失效時回到目前條件的第一頁，包括 2026 年 10 月 31 日更新之前儲存的搜尋分頁連結。
- RSS 沒有分頁，Torznab 使用有界 `offset`。

## 播出狀態

自動判定完結需要明確的首播日期與結束日期，且來源在結束日完整過去後再次確認結束日期。日期按日本時間比較；只有年份、月份、季度或作品類型，不能據此判定完結。

來源更正播出計畫後，自動狀態會隨同步重新計算。人工鎖定的狀態以及明確的停播、取消狀態優先。證據不足的作品標為未知，不沿用缺乏依據的歷史狀態，也不把計畫結束日當成已完結證明。

首頁同一作品同一天只顯示最新一集；正常跨日連播仍分別顯示。
