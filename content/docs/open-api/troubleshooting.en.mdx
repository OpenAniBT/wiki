Application JSON errors identify the request in error.requestId, usually also in X-Request-ID. Plain text, XML, redirects, and edge responses do not guarantee this field. Report the endpoint, time, HTTP status, and available request ID; never include keys, cookies, or private RSS URLs.

An authorized DELETE of an already deleted release returns the original deletion operation. If DELETE returns 404, the release never existed, belongs to another group, or this key may not delete it (a plain member's key that targets another member's release gets the same response as for a release that does not exist). Do not treat that 404 as proof of completion. Read `/deletion` for the same releaseId.
