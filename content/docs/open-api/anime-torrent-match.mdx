          解析发布标题与种子内部名，返回 auto / manual 等决定。
          正式括号副标题、罗马音和英文别名分别保留，季数与集数分别识别。多个标题指向不同作品时，仍需人工确认。
          数字标题词不自动纠错或忽略。宽松匹配最多忽略一个普通词，且不能单独授权 auto；无法可靠识别的标题仍可能没有候选。
          传入 `groupId` 时必须登录且属于该组。GET 返回 `405 METHOD_NOT_ALLOWED`。
          公开路由 `diagnostics=true` 返回 `403`。请求体上限 32 KiB。不缓存。
          Matcher 只在本接口。不要把调用方伪造的匹配结果传给发布接口。
          发布接口必须带 `animeIdType` 与 `animeId`。
          `limit` 默认 10，上限 50。速率限制默认 180 次 / 60 秒 / IP。
          成功响应直接返回 version、content、decision、candidates 等字段，没有 ok 或 data 包装。
          未提供 infoHashHex 时 decisionToken 和 decisionTokenExpiresAt 为 null。只有 decision.kind=auto 时才可采用已列入 candidates 的决定；manual 必须由调用方确认。
          匹配暂时无法完成时仍返回 200：`decision.kind=unavailable`，`decision.reason=search_unavailable`，`candidates` 为空。这不表示番剧不存在；稍后重试，或由调用方手动选择番剧。
