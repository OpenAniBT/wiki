          查询该 API Key 所属字幕组的普通 release 在六个外站的同步状态。

          请求只支持 `rel_...` 形式的 `releaseId`，且资源必须属于当前 Key 所属字幕组。

          不存在、已删除或跨组资源统一返回 `404 NOT_FOUND`。

          成功响应为 `{ ok: true, data: { releaseId, title, publishedAt, overall,
          sites } }`。

          `data.sites` 是数组，固定包含 `mikan`、`acgrip`、`bangumi`、`acgnx`、`dmhy`、`nyaa`
          六个平台。遍历数组并用每项的 `site` 字段识别平台；不要读取 `data.mikan` 或 `data.nyaa`。

          每站提供当前状态、`externalId`、`externalUrl`、错误、`generation`、`attempt`、时间戳、最近
          50 条 `history` 和该站的 `historyTruncated`。所有时间戳均为 Unix 毫秒。

          站点状态为 `not_started`、`pending`、`success`、`failed`、`ambiguous` 或
          `deleted`。

          `data.overall` 是字符串：任一站为 `failed` 或 `ambiguous` 时为 `failed`；全部成功时为
          `success`；全部未开始时为 `not_started`；其余情况有 `pending` 时为 `pending`，否则为
          `partial`。

          接口不会返回外站原始响应正文或凭据，响应使用 `Cache-Control: no-store`。

          需要 `releases:sync:read`。

          不接受 query 或请求体。默认 120 次 / 60 秒 / API Key；超限按 Retry-After 退避。
