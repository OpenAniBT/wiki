AniBT 运行着专为本站发布的动漫资源提供高速对等连接服务的自建 BitTorrent Tracker。

<Callout type="warn">
  **白名单通信机制**：为了防范恶意刷流与垃圾种子滥用，AniBT Tracker 启用了 infohash 白名单机制。只有在 AniBT 成功发布的种子才会自动加入通信白名单。未在本站发布的种子汇报时会返回 `not whitelisted`。
</Callout>

## 官方 Tracker 地址

在制作 `.torrent` 文件或在下载客户端中配置 Tracker 时，请使用以下标准地址：

```txt title="AniBT Tracker Announce URL"
https://tracker.anibt.net/announce
```

- **通信协议**：使用 HTTPS（端口 443）连接。
- **当前不可用**：UDP 尚未启用；公网 `/scrape` 与历史 `/announce/v1/*` 路径保持关闭。

## 查看运行状态

访问 [Tracker 状态页](https://tracker.anibt.net/) 查看做种节点、下载节点、记录种子、累计完成和连接数量。可切换近 30、60、90 分钟的历史，以及节点、种子、完成记录和连接视图。

数据每分钟更新。快照过期或无法获取时会明确提示；缺失数据显示 `—`，图表不补造历史。节点按每个种子计数，不等于独立用户人数。连接数量包含等待连接，不等于做种或下载人数。

所选时间窗口保持完整跨度，缺失区间以阴影标记，曲线不会跨过缺口。每张图标明有效采样数量与实际采样范围；上报均值只计算有效样本。

纵轴默认「从零」开始。查看累计完成数等指标的小幅变化时，可切换「自适应」；图下会标明纵轴起点。累计完成仍表示累计数量。

移动指针或在手机上轻点图表可查看精确时间与数值；点到缺口会提示没有采样。图表取得焦点后，按左右方向键逐点查看，<kbd>Home</kbd> / <kbd>End</kbd> 跳到首尾，<kbd>Esc</kbd> 退出。展开「查看采样明细」可读取当前窗口的逐条记录。

## 制种与发布流程

<Steps>
  <Step>
    ### 在制种工具中添加 Tracker
    使用 qBittorrent、Transmission、mktorrent 等制种工具创建种子时，将 `https://tracker.anibt.net/announce` 填入 Tracker 服务器列表第一行。
  </Step>

  <Step>
    ### 在 AniBT 平台提交发布
    通过字幕组后台页面或 [发布 API](/docs/open-api/releases-publish) 上传生成的 `.torrent` 文件。平台成功受理入库后，会自动将该种子的 infohash 写入 Tracker 通信白名单，同时生成携带该 Tracker 的磁力链接。
  </Step>

  <Step>
    ### 客户端做种上传
    在下载客户端中加载该种子，确认 Tracker 状态显示为 `working`（正常通信）。此后其他从 AniBT 获取磁力或种子的观众即可通过该 Tracker 与你建立对等连接。
  </Step>
</Steps>

## 种子文件下载接口

AniBT 为全站公开资源提供直接的 `.torrent` 二进制文件下载路径，第三方工具与脚本可按需调用：

<TypeTable
  type={{
    '番剧资源种子': {
      type: 'GET',
      description: 'https://anibt.net/api/torrent/{releaseId}.torrent（releaseId 以 rel_ 开头）',
    },
    '其他类资源种子': {
      type: 'GET',
      description: 'https://anibt.net/api/other-torrent/{releaseId}.torrent（releaseId 以 orel_ 开头）',
    },
  }}
/>

## 做种统计接口

按资源 ID 批量查询做种数、下载数和完成数。无需登录，允许跨域调用。请求和响应都不包含 infohash。

<Callout title="POST https://anibt.net/api/tracker-stats/batch">
  请求体为 JSON，在 `releases` 中列出要查询的资源。
</Callout>

```json title="请求示例"
{
  "releases": [
    { "kind": "release", "releaseId": "rel_dE7jiWrXPwPw" },
    { "kind": "other-release", "releaseId": "orel_wiki_audit_missing" }
  ]
}
```

<TypeTable
  type={{
    'releases': {
      type: 'array',
      description: '要查询的资源，最多 200 项。重复项只计一次；默认只返回前 60 个不同资源，其余资源不出现在响应中。',
    },
    'releases[].kind': {
      type: '"release" | "other-release"',
      description: '番剧资源（ID 以 rel_ 开头）填 release，其他类资源（ID 以 orel_ 开头）填 other-release。',
    },
    'releases[].releaseId': {
      type: 'string',
      description: '资源 ID，1–180 个字符。',
    },
  }}
/>

响应的 `statsByRelease` 按 `kind` 和资源 ID 分组，`release` 与 `other-release` 两组始终存在。`now` 为服务器时间，单位为 Unix 毫秒。

```json title="响应示例"
{
  "statsByRelease": {
    "release": {
      "rel_dE7jiWrXPwPw": {
        "state": "fresh",
        "seeders": 53,
        "leechers": 44,
        "completed": 64,
        "updatedAt": 1791023419906,
        "refreshQueued": false
      }
    },
    "other-release": {
      "orel_wiki_audit_missing": { "state": "unavailable" }
    }
  },
  "now": 1791023794205
}
```

<TypeTable
  type={{
    'state': {
      type: '"fresh" | "stale" | "missing" | "unavailable"',
      description: 'fresh：近期测得。stale：测得时间较早，数字仍有效，以 updatedAt 为准。missing：资源公开，但还没有测量结果；不含计数，不表示 0。unavailable：资源不存在、已删除、未公开或没有种子信息；只含 state。',
    },
    'seeders / leechers / completed': {
      type: 'number',
      required: false,
      description: '做种数、下载数和完成数。仅 fresh 与 stale 包含。',
    },
    'updatedAt': {
      type: 'number',
      required: false,
      description: 'Tracker 最后一次应答的时间，单位为 Unix 毫秒。仅 fresh 与 stale 包含。',
    },
    'refreshQueued': {
      type: 'boolean',
      required: false,
      description: 'true 表示本次请求已安排刷新，稍后可再次查询。unavailable 不含该字段。',
    },
  }}
/>
