title: 開始使用
description: 歡迎使用 AniBT。瞭解如何作為字幕組釋出資源、作為觀眾下載追番，或作為開發者使用開放 API。
---

AniBT 是面向動漫愛好者與字幕組的 BT 資源分發、索引與檢索平台。

<Callout type="info">
  瀏覽全站資源、複製磁力、下載種子以及使用公開 RSS 均無需登入。僅當需要收藏番劇、管理個人訂閱，或以字幕組成員身份釋出資源時，才需要註冊帳號。
</Callout>

無論你是製作動漫資源的字幕組、尋找高畫質動畫的追番黨，還是開發相關工具的技術愛好者，都可以在這裡找到對應的使用方式。

## 快速導覽

<Tabs items={['字幕組工作流程', '觀眾與追番', '開發者與 API']}>
  <Tab value="字幕組工作流程">
    字幕組在 AniBT 提交一次釋出後，後台會自動同步至全網各大 BT 站，並享有專屬圖床與 Tracker 通訊支援。

    <Steps>
      <Step>
        ### 申請入駐
        註冊主站帳號後，透過郵件提交字幕組資訊與以往作品證明，取得字幕組管理後台權限與釋出專屬 slug。詳見 [申請入駐](/zh-Hant/docs/apply)。
      </Step>
      <Step>
        ### 設定外站同步與 Tracker
        在字幕組控制台填入各 BT 分發站（萌番組、蜜柑計畫、動漫花園、末日站、ACG.rip、Nyaa）的憑據。製種時加入 [AniBT Tracker](/zh-Hant/docs/tracker)。詳見 [站點同步](/zh-Hant/docs/site-sync)。
      </Step>
      <Step>
        ### 釋出資源
        在後台頁面直接上傳種子製種釋出，或透過 [釋出 API](/zh-Hant/docs/open-api/releases-publish) 接入自動化壓制釋出腳本。支援釋出前效果預覽與專屬圖床配圖。

        釋出時，如果番劇搜尋提示暫時無法使用，請稍後重試；這不表示番劇不存在。已知 BGM ID 時，可直接用 ID 綁定番劇。

        一般編輯適用於番劇與其他類資源的中繼資料，不能新增、替換或移除原始種子。已有種子時，磁力連結必須保留同一 v1 `infohash`；可以修改 tracker、顯示名稱等附加參數。只有磁力連結的釋出仍可修改磁力，但不能透過一般編輯附加種子。
      </Step>
    </Steps>
  </Tab>

  <Tab value="觀眾與追番">
    無需繁瑣註冊，開箱即用的動漫搜尋與全自動追番體驗。

    <Steps>
      <Step>
        ### 檢索與下載
        在主站首頁或番劇頁面，可透過動畫中文名、日文原名、Bangumi 詞條或字幕組標籤精準檢索。每個資源詳情頁均提供磁力連結與標準 `.torrent` 檔案下載。

        資源詳情頁、`/magnets`、番劇頁面，以及點選番劇海報後展開的資源面板，都在點選按鈕時才取得下載地址：

        - 「複製磁力連結」「開啟磁力連結」：點選後取得磁力連結。取得失敗時提示「下載地址不可用」。瀏覽器拒絕寫入剪貼簿時，點選提示中的「再次複製」；瀏覽器未能直接開啟磁力連結時，點選提示中的「再次開啟」。
        - 「下載種子」：直接下載 `.torrent` 檔案。番劇頁面和展開面板中的種子按鈕也直接下載，不再跳轉到資源詳情頁。
        - 檔案列表：在資源詳情頁點選「查看檔案列表」後載入，載入完成後顯示檔案數。

        番劇頁面的「資源」頁籤有自己的網址 `/anime/<id>?tab=releases`，預設的「發布進度」頁籤是 `/anime/<id>`。`/magnets` 與字幕組主頁「發布」頁籤的上一頁、下一頁是帶 `cursor` 參數的連結，可以在新分頁開啟或分享。字幕組「發布」頁籤的季度篩選也寫在網址中（`season` 與 `year`，或 `all`），每頁 20 條。分頁連結失效時回到目前條件的第一頁。
      </Step>
      <Step>
        ### RSS 訂閱追番
        複製番劇專屬的 [RSS 訂閱連結](/zh-Hant/docs/open-api/rss-anime)，填入 qBittorrent、Sonarr 或 FlexGet 等下載工具。新集數釋出後，下載工具會自動拉取種子並開始下載。
      </Step>
      <Step>
        ### 個人訂閱管理（可選）
        登入後，在番劇頁面點選「訂閱本作」，可依字幕組、字幕語言、解析度、檔案格式、字幕類型和標籤篩選，再點選「訂閱」。不限制的條件保持「全部」。

        修改時，在番劇頁面或「我的訂閱」的番劇卡片上開啟「訂閱設定」。已有條件會自動填入，可先修改；其他篩選選項會繼續載入，載入失敗時可重試，已修改的條件會保留。點選「儲存」後生效；點選「取消」不會修改訂閱。同一篩選項內多選符合任一選項，不同篩選項需同時符合。

        在「我的訂閱」複製[個人訂閱 RSS](/zh-Hant/docs/open-api/rss-subscriptions) 的完整連結，即可在下載工具中接收符合條件的資源。個人連結包含存取憑證，請勿公開；番劇頁面的公開 RSS 連結不使用個人篩選條件。
      </Step>
    </Steps>
  </Tab>

  <Tab value="開發者與 API">
    全站數據公開透明，提供規範的 REST API 與標準 RSS 輸出。

    <Steps>
      <Step>
        ### 探索公開端點
        所有讀取介面無需申請 Token 或設定鑑權，涵蓋番劇查詢、搜尋召回、字幕組目錄與最新磁力聚合。詳見 [開放 API 總覽](/zh-Hant/docs/open-api)。
      </Step>
      <Step>
        ### 啟用 304 條件請求
        公開端點全面支援弱 ETag 與 `If-None-Match`。在輪詢腳本中攜帶 ETag 即可在內容無變更時直接回傳 `304 Not Modified`，大幅節省網路開銷。詳見 [HTTP 快取](/zh-Hant/docs/open-api/caching)。
      </Step>
      <Step>
        ### 字幕組自動化接入
        持有字幕組 API Key 的開發者可透過 REST API 完成資源釋出、元數據核對、外站同步狀態追蹤與資源撤回。
      </Step>
      <Step>
        ### 抓取與網站地圖
        主站 `robots.txt`、網站地圖分片、各類頁面的收錄規則、三種語言網址的互指（hreflang）和 IndexNow 通知見 [LLM 與 Agent 對接](/zh-Hant/docs/llm)。
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 釋出標題範本

標題範本根據釋出表單中的技術標籤產生編碼、位元深度、音訊與來源欄位。自訂範本和內建範本使用相同的拼寫規則；方括號、圓括號和字幕語言標籤保留各範本的樣式。

```text title="將編碼與位元深度放在同一對方括號內"
[{{codecBitDepth}}]
```

例如，`H.264` 與 `8 bit` 輸出 `[AVC 8bit]`，`HEVC-10bit` 輸出 `[HEVC 10bit]`。編碼與位元深度之間使用一個空格。只提供編碼或位元深度時僅顯示已有欄位，兩者都沒有時移除空括號。也可以分別使用 `codec` 和 `bitDepth` 自行排版。

<TypeTable type={{
  "codec": { type: "string", description: "視訊編碼的標準名稱，例如 AVC、HEVC、AV1、VP9、MPEG4、VC-1、ProRes。" },
  "bitDepth": { type: "string", description: "已識別的位元深度，統一為 8bit 或 10bit；不根據編碼猜測缺少的位元深度。" },
  "audioCodec": { type: "string", description: "音訊編碼採用統一拼寫，例如 AAC、OPUS、TrueHD、DTS-HD MA；保留標籤中的聲道資訊。" },
  "source": { type: "string", description: "來源採用統一拼寫，例如 WebRip、WEB-DL、BDRip、DVDRip。名稱本身的連字號會保留。" },
  "dimensions": { type: "string", description: "依所選解析度產生的標準尺寸，與 resolution 的 dimensions 格式化結果相同；這不是對視訊檔案的實測。480p 對應 854x480，360p 對應 640x360。" }
}} />

格式規範只用於重新產生範本標題，不回寫已儲存的技術標籤，也不會批次修改已釋出標題或原始種子檔名。無法識別的自訂標籤會保留在包含額外標籤的範本中。

## 介面語言

AniBT 主站有簡體中文、繁體中文和英文三種介面語言。頁面語言只由網址決定，三種網址一一對應。

<TypeTable
  type={{
    '简体中文': {
      type: '不帶前綴',
      description: '例：https://anibt.net/anime/617123',
    },
    '繁體中文': {
      type: '/zh-hant/',
      description: '例：https://anibt.net/zh-hant/anime/617123',
    },
    'English': {
      type: '/en/',
      description: '例：https://anibt.net/en/anime/617123',
    },
  }}
/>

- 每個頁面都有三種網址，包括公開頁面、登入與註冊頁面、個人頁面和字幕組後台。在繁體中文或英文頁面登入後，會回到同一語言的頁面。
- 語言選單中的其他語言連結到目前頁面的對應網址，並記住你的選擇。手動選擇的語言優先於瀏覽器語言。
- 在目前分頁首次直接開啟首頁 `/` 時，網站先使用已記住的語言，再依瀏覽器語言清單選擇支援的語言：英文進入 `/en`，繁體中文進入 `/zh-hant`；簡體中文或沒有符合的語言時留在 `/`。`en-US`、`en-GB` 視為英文，`zh-TW`、`zh-HK`、`zh-MO` 視為繁體中文。
- 每個分頁最多自動偵測一次。同一分頁再次直接開啟 `/` 時會保留簡體首頁；從詳情頁透過站內連結返回首頁也不會觸發偵測。帶語言前綴的網址和其他頁面始終依網址顯示對應語言。
- 自動跳轉需要瀏覽器允許執行指令碼和使用工作階段儲存空間，跳轉前可能短暫顯示簡體首頁。被識別為爬蟲或自動化工具的存取不參與自動跳轉。需要其他語言時，隨時可以使用語言選單。
- 沒有自動跳轉時，以前選過繁體中文或英文的讀者開啟不帶前綴的頁面，會看到一次切換提示。點選「切換」或「Switch」開啟同一頁面的對應語言網址；不點選時保留目前頁面。
- 主站的語言前綴只用小寫，`/zh-Hant/…`、`/EN/…` 回傳 404。本 Wiki 的繁體網址 `/zh-Hant/docs/…` 是另一套規則。
- 介面文字隨語言改變。釋出標題、釋出說明和字幕組名稱在三種語言中都保持原文。
- 繁體中文頁面中的番劇名稱使用官方繁體譯名；沒有官方譯名的番劇由簡體名稱自動轉換為繁體，番劇簡介同樣自動轉換。簡體中文和英文頁面顯示簡體中文的番劇名稱和簡介。
- API（`/api/…`）、RSS、Torznab、網站地圖、`robots.txt`、釋出預覽連結、登入回呼與 OAuth 授權網址只有一個網址，不帶語言前綴。
