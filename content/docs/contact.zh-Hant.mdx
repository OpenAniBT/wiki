AniBT 是由動漫愛好者與開源技術貢獻者維護的社群平台。如你在使用過程中遇到任何疑問、需要申請權限或處理版權事務，均可透過官方信箱與我們取得聯絡。

<Callout type="info">
  **官方聯絡信箱**：[support@anibt.net](mailto:support@anibt.net)
</Callout>

## 常見事務與郵件規範

為了幫助我們更快定位並協助你處理問題，建議按以下分類與規範發送郵件：

<Tabs items={['字幕組入駐 / 白名單', '技術故障與 API 排障', '版權處理與下架 (DMCA)', '功能建議與回饋']}>
  <Tab value="字幕組入駐 / 白名單">
    - **郵件主題**：`字幕組入駐申請 - <組名>` 或 `Nyaa代發白名單申請 - <組名>`
    - **發件信箱**：務必使用在 AniBT 註冊的主帳號信箱發送。
    - **必要內容**：組名、slug、作品簡介、以往釋出證明（花園/蜜柑等首頁連結）。詳見 [申請入駐指南](/zh-Hant/docs/apply)。
  </Tab>

  <Tab value="技術故障與 API 排障">
    - **郵件主題**：`【故障回饋】<發生異常的頁面或介面名>`
    - **必要內容**：
      1. 發生問題的具體 URL 或請求端點
      2. 呼叫的 curl 指令或請求體參數（請遮蔽私密金鑰敏感資訊）
      3. 介面回傳的錯誤 JSON，尤其是其中的 `requestId` 欄位；在網頁上遇到錯誤時，複製提示末尾的「錯誤代碼 · 請求 ID」，或錯誤頁上「複製全部」得到的內容
      4. 發生問題的時間（精確到分鐘）
  </Tab>

  <Tab value="版權處理與下架 (DMCA)">
    - **郵件主題**：`DMCA Takedown Notice - <資源名稱>`
    - **必要內容**：版權所有者證明文件、授權證明、涉及侵權的 AniBT 資源詳情頁完整連結，以及權利人的法定聯絡方式。我們將在核實後依法迅速處理。
  </Tab>

  <Tab value="功能建議與回饋">
    - **郵件主題**：`【建議】<你的想法概括>`
    - **必要內容**：歡迎提出關於站點使用體驗、RSS 過濾功能、多站同步最佳化等任何建議。如果是針對開源生態工具的改進，也可以直接前往對應的 GitHub 倉庫提出 Issue。
  </Tab>
</Tabs>

## 處理與回覆時效

- **常規事務**：通常在 **1 至 3 個工作天** 內完成核實並回覆。
- **版權下架**：收到完備材料後將在工作天 **24 小時內** 優先回應與處理。
- **排隊提醒**：若超過 7 天未收到任何回信，請先檢視信箱的「垃圾郵件箱」是否誤攔截；確認未收到後可發送郵件跟進。
